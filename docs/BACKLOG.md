# WorldLoom 后续任务

任务按风险和依赖排序。已完成能力不在此重复登记，当前开放项见 [ISSUES.md](./ISSUES.md)。

## P0/P1：发布前必须完成

1. 在实际部署环境完成外部认证接入和限流并发压测。
2. 完成跨主机 PostgreSQL 备份恢复演练和迁移回滚演练。
3. 验证独立 worker 的 lease、重试、幂等写入、容量和故障恢复。
4. 为正式 provider 填写真实价格和 token 预算，并重新运行严格 preflight。
5. 在目标硬件上复跑检索、编译和容器资源基准。

## P2：按使用信号推进

- 真实创作试用：用连续数日的半成品素材记录生成质量、耗时、成本和工作流阻塞。
- 图谱进阶：路径查找、聚类折叠和按类型筛选。
- 技能发布审批、权限和批量管理。
- 当单世界实体与事件达到数千且延迟明显时，评估 PostgreSQL FTS/GIN 索引。
- 当表单复杂度继续增长时，统一迁移到 TanStack Form。

## 明确暂不做

公网多租户认证、多人实时协作、游戏 NPC 运行时、移动端应用和未经规模验证的高可用集群。
