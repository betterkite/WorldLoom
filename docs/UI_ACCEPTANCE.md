# WorldLoom 页面验收

页面验收使用真实 Chromium，对主要工作区执行结构、几何、可达性、渲染和交互检查。

## 覆盖范围

世界总览、条目、条目详情、编年史、时间线、图谱、故事创作、世界知识助手、一致性检查、
版本、运行治理、素材、创世向导、评测平台和技能库。

## 必查项目

- HTTP 状态、控制台错误和失败请求。
- 横向溢出、文本裁切、绝对定位面板和折叠侧栏。
- 按钮/链接可访问名、表单标签、键盘可达性和对比度风险。
- SVG 时间线图元、WebGL 图谱像素（WebGL 不可用时检查 SVG 兼容渲染是否完全遮住未完成画布，避免重复节点重影）和加载/空数据状态。
- 关键交互：条目弹窗、节点详情、ego 邻居、时间切片、章节编辑和评测跑分。
- 图谱进阶：节点类型筛选、当前筛选范围内的最短路径和总览社区折叠。
- 页面不能依赖演示数据或隐藏的外部服务才能渲染。

## 执行

日常功能复核可以复用已经运行的候选，先走下面的轻量路径；完整自动化命令用于准备好的
隔离验收环境。`ui-shots` 会创建并保留演示世界，其他验收脚本也可能写入数据，不能把正在
使用的个人数据库直接当作测试数据库。

```bash
pnpm build
node scripts/ui-shots.mjs
# 复制 ui-shots 输出的 WORLD_ID
node scripts/ui-acceptance.mjs http://localhost:4310 world-id-from-ui-shots
```

验收脚本需要已启动的应用和可用测试数据库。截图目录默认被 Git 忽略，不作为产品源文件
提交；需要审阅视觉设计时，可在本地保存并单独提供截图。GitHub Actions 的 E2E job 会在真实
Chromium 验收后保留失败时的截图证据。

验收 fixture 使用唯一 ID；重复运行不会删除或复用数据库中其他同名前缀的世界。截图写入
`screenshots/<run-id>/`，演示世界保留以便后续页面验收和人工检查；检查完成后只通过应用界面删除
本次 `WORLD_ID` 对应的演示世界（也可调用 `DELETE /api/worlds/<WORLD_ID>`）。不得按名称前缀清理。

## 轻量功能复核

在独立合成数据库和候选页面上串行操作，每项完成后再进入下一项。该路径不需要执行
全量构建、压力脚本或点击模型生成按钮，也不替代最终发布门禁。

1. 打开世界列表，新建一个本次专用的合成世界，确认能进入设定条目和故事创作。
2. 在「新建/导入作品」中通过文件选择器导入两章小 TXT，确认正文预览、章节标题和章数。
3. 编辑首章标题与正文，保存；刷新页面后重新选择作品、查看该章，核对修改和末尾换行。
   当前刷新不会自动重新选中作品，作品仍在列表中，不应将未选中状态误判为文稿丢失。
4. 将浏览器窗口缩窄到侧栏进入抽屉布局，打开侧栏并点击「世界列表」，确认导航成功且
   抽屉收起。再打开不存在的世界深链，确认显示恢复文案，侧栏和返回列表入口仍可使用。
5. 若同时复核接口，在同一合成库确认待审变更合并前不写正史，合并与回滚均追加版本；
   不以页面 HTML 能返回就推断这些数据行为正确。

大文本适用性另需核对分批写入、存储拼接、目录摘要和单章读取，不用全文付费编译或
堆叠容器来代替。任何模型调用、个人数据库操作或现有服务升级应单独确认操作范围。
