# WorldLoom 页面验收

页面验收使用真实 Chromium，对主要工作区执行结构、几何、可达性、渲染和交互检查。

## 覆盖范围

世界总览、条目、条目详情、编年史、时间线、图谱、故事创作、世界知识助手、一致性检查、
版本、运行治理、素材、创世向导、评测平台和技能库。

## 必查项目

- HTTP 状态、控制台错误和失败请求。
- 横向溢出、文本裁切、绝对定位面板和折叠侧栏。
- 按钮/链接可访问名、表单标签、键盘可达性和对比度风险。
- SVG 时间线图元、WebGL 图谱像素（WebGL 不可用时检查 SVG 兼容渲染）和加载/空数据状态。
- 关键交互：条目弹窗、节点详情、ego 邻居、时间切片、章节编辑和评测跑分。
- 图谱进阶：节点类型筛选、当前筛选范围内的最短路径和总览社区折叠。
- 页面不能依赖演示数据或隐藏的外部服务才能渲染。

## 执行

```bash
pnpm build
node scripts/ui-shots.mjs
node scripts/ui-acceptance.mjs
```

验收脚本需要已启动的应用和可用测试数据库。截图目录默认被 Git 忽略，不作为产品源文件
提交；需要审阅视觉设计时，可在本地保存并单独提供截图。GitHub Actions 的 E2E job 会在真实
Chromium 验收后保留失败时的截图证据。
