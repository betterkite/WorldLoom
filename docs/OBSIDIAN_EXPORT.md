# Obsidian 导出

世界导出 ZIP 是当前主版本的只读笔记快照，包含条目、事件、时间线和关系。
导出不会合并待审变更，也不会改变历史版本。游戏 JSON 导出是另一个独立格式。

条目和事件文件名包含可读名称及稳定 UID 标识。同名、名称清洗后相同或大小写不同的
内容会保留为不同文件；文件名按 UTF-8 字节限制长度。显示名称、别名、标签及来源引用
保存在笔记属性中，特殊字符不会被解释成额外属性或其他数据类型。

生成的参与者、关系、时间线和因果链接使用准确的笔记路径。一个事件的多个起因都会
保留；缺失目标会明确显示缺失引用。未知年月日保留为 `null`，不据导出顺序补造日期。

正文中指向本次快照的已知、唯一 wiki 链接会改写到对应路径，显示别名和章节锚点保留。
同名目标不会被随意指定，导出会显示未解析的同名引用。外部笔记链接和代码示例保留原文；
导出不检查其他 Obsidian 仓库中是否存在目标，也不验证用户自写的章节锚点。

这个格式修正改变了旧版只按名称生成的文件名。每次快照解压到独立目录，避免与旧快照
混合产生陈旧笔记。已有 Obsidian 仓库中的其他笔记或外部链接不会由 WorldLoom 自动迁移。
