# 大文本适用性（本机单人）

2026-10-01：验证目标是长文能正常导入、分章、保存、浏览和编辑，不是压满内存或并发调用
模型。不要为此额外启动多副本、模型压力负载或并行镜像构建。

## 当前候选补证（2026-10-31）

当前完整 Webpack standalone 候选在独立合成 PostgreSQL 中，由真实 Edge 前端文件选择器
导入 225,942 字节 TXT，规范化后 78,109 个 Unicode 字符（78,112 个 UTF-16 单元）。
三个长章形成六个草稿切片，单片最多 19,999 个 UTF-16 单元；前端实际先创建五片、再
追加一片，两次请求均成功。逐字拼接与 BOM/换行规范化原稿相同，重复段落、特殊字符和
末尾空白保留。目录响应只含摘要，查看和编辑按需读取单片。

末片标题及正文追加经前端保存后，刷新、重新选择作品和打开末片仍可见；只读接口确认
保存内容逐字一致。六片保持草稿，世界仍 v1、零待审，未生成编译任务或模型调用记录。
单个临时容器限 768 MiB/1 CPU，峰值 328,470,528 字节，无 OOM，结束后已清理。

这是本机人工代理操作观察和合成数据核对，不是全量 E2E、无限规模性能、批次失败恢复
或模型内容质量证明。先前 3.46 MB 合成稿的无损前端验收保留其原日期与源码范围；本轮
不重新运行该规模、全文付费编译或压力测试。下方各日期的“尚待”保留历史语境，不应
覆盖此处已经完成的有限导入、保存和读取证据。

## 数据路径

- TXT/Markdown 导入规范化 BOM 与换行。真实章节标题优先于装饰分隔线；长章保留名称和分片号。
- 每片仍不超过 20,000 UTF-16 单元；按句末或换行切分。存在标题时保留标题原文及全部正文。
  `---` 手工分章仍保留分章行为，同时把分隔线保留在前一章末尾；不去重重复正文。
  2026-10-11：浏览器与纯文本 API 统一使用该无损切分契约，创建路径保留空白尾部；追加
  API 和服务层也执行 20,000 上限，非法批次在写入前拒绝。尚待本次隔离回归，不据此声称
  最新浏览器或编译闭环已通过。
- 导入仍按最多 5 片/100,000 字符逐批提交。失败不清空输入；成功后释放导入框及 mutation 中
  不再需要的全文。中途批次失败后的可靠断点续传/幂等尚待完善，不能宣称已实现。
- 前端目录请求使用 `?chapters=summary`，只返回标题、状态、顺序及 Unicode 字符数。
  字符数由 PostgreSQL 计算，不把所有正文读进 Node 和浏览器只为显示长度。
- 点击查看/编辑才 GET 单章正文；加载失败允许重试。章/作品读取严格匹配所属世界。
  既有不带参数的完整作品 API 保持兼容。

编译仍分块、持久化任务、先生成待审 Change，不自动合并正史。API 与 worker 共用进程级
执行闸门；不同进程的总并发不是单个进程的 cap。`WORLDLOOM_COMPILE_CHUNK_SIZE` 可显式
选择 1,000–8,000 的测量配置；默认仍为 1,000，已有任务保持原分块，尚无大块质量批准。

可选累计费用保护由 `WORLDLOOM_LLM_BUDGET_CNY` 和绝对路径
`WORLDLOOM_LLM_BUDGET_LEDGER` 启用，要求 profile 有核验过的 CNY 价格。账本必须位于
可写、可持久化的本地卷；跨进程共享预算须共享同一文件。每次请求（含重试）预留输入
UTF-8 字节数加模板余量、最大输出对应的费用，完整 usage 才释放多余预留；不明用量、
错误账本或锁冲突停止新请求。它是按已配置价格的保守费用估算，不是 provider 账户硬额度，
也不允许删除账本后重置预算。5 元是一次测试的授权，不是产品永久默认额度。
默认模型思考模式没有为测试而改动。

部署预检已补入可选累计 CNY 配置检查：成对参数、可安全表示的正数金额、绝对账本路径、
默认 profile 的 CNY 价格及 HTTPS/日期时效。没有启用时只明确提示未设置累计保护；错误配置
在普通/strict 模式都阻断。预检不读写账本，不证明共享挂载、真实用量或账户价格已验证，
也不替代原 strict 门禁。本次新增预检用例同样尚未执行。

预算阻断的公开响应统一为 `429 / llm_budget_exceeded`，提示检查预算与用量记录，不携带
账本路径、profile 私有信息或自动 `Retry-After`。它覆盖操作级 usage 预算与累计 CNY 账本；
真实 provider 故障仍走原来的 502/503。10/1 此反馈修复已补入源码与回归用例，但用户选择
暂不运行验证，当前不将它记为测试或浏览器验收通过；正在运行的旧镜像也尚未更新。

另补入运行时操作预算的配置错误阻断：显式非法覆盖不再回退到旧 profile 额度或空预算，
而是在模型请求前报错，API 为 `503 / llm_budget_config_invalid`、无自动重试提示。
未设置的覆盖仍沿用原配置，其他 profile 不套用默认 profile 的覆盖。该修复/用例尚未验证，
不能据此声称已完成账单或实际费用验收。

## 已有证据与边界

9/30 的旧候选经真实前端文件 chooser 导入一份 2,899,799 bytes、约 97 万字符的 TXT，
产生 51 个草稿，没有复现全局渲染错误。之后修正分章规则，在内存中的单次解析得到
78 片（max 19,999），拼接结果与 BOM/换行规范化后的 970,285 字符逐字一致。
后者是解析证据，不能冒充新规则的浏览器或模型编译验收。原文不进入产品仓库。

10/1 的 SQL/API 集成测试证明目录不包含章节或候选正文、单章读取和跨世界 404；包含
20,000 字合成单章，不运行真实模型。隔离副本 44 文件/312 项常规回归通过。
查看/编辑的浏览器用例已补，最新界面和生产制品仍待串行复验；不据此声称全部大文本体验
或创作质量已验收。用户取消全文压力测试后没有启动付费编译，临时测试容器已删除。

下一步以单个本机实例完成低资源的导入→保存→按章浏览/编辑验证，记录失败及恢复；不能
用全量付费编译替代这些前端适用性检查。模型内容质量仍按 `V0_1_RELEASE.md` 单独验收。
