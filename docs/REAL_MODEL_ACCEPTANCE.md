# 真实模型链路证据

日期：2026-09-30。范围：本机开发候选 `0.1.0-dev.0`，未提交、未上传；不代表正式发布批准。
关联问题：[ISS-33 / #4](https://github.com/betterkite/WorldLoom/issues/4)。

## 环境和素材

- 在独立、空数据库应用 15 个迁移，应用仅绑定 `127.0.0.1:4311`；不使用现有用户世界。
- 默认模型为 DeepSeek `deepseek-flash`。公开价格与当前配置在当日核对一致，来源为
  [官方价格表](https://api-docs.deepseek.com/quick_start/pricing/)；估算采用峰值、输入 cache-miss
  单价，不等于账单，也不代表获得生产预算批准。
- 本次运行专用的软 guard：每操作输入 50,000 tokens、输出 12,000 tokens、估算成本 USD 0.05。
  没有修改本机现有服务或账户级硬额度；重试、失败调用及其他操作的完整账单不能由编译记录推出。
- 使用脚本内置的合成仙侠前提和短增量设定。增量包含云隐子、向顶天、守梦人、断梦派及明确师徒关系；
  没有上传私有文稿，不把该样本称为代表性用户试用。

## 内容抽查与回退

两轮都观察到版本 `[1,2,3,4]`；创世、编译及推演采纳在合并前保持 masterVersion 不变、存在
pending Change，合并后才追加版本。最终 lint findings 为空。

Agent 抽查选定条目、问答记录和引用：云隐子为向顶天师父、断梦派来自守梦人等明确事实被保留；
答案列出引用并说明向顶天具体阵营/立场没有足够依据。这仅是有限样本核对，未取得创作者的人工
质量批准，也未覆盖长篇连续性、不同体裁、冲突素材或全部自动生成细节。

独立的单条合成 embedding 输入探测返回 HTTP 402（上游原文未输出）。同一运行环境仍完成
语义索引，健康摘要显示本地 `Xenova/bge-m3` 已加载、1024 维；未出现 embedding 余额字段。
此为远程不可用时的本机本地回退证据，不是目标环境的容量/故障/高可用证明。

两轮使用 `--keep-world` 暂留 fixture 供抽查；完成后各自核验精确 ID 和 UUID 名称，再 DELETE
200、GET 404。原有用户库仍为 5 个世界。生成内容、凭据、截图与数据库备份不进入产品 Git。

## 仍待补齐

1. 代表性素材的持续试用、创作者人工复核、失败恢复和阻塞记录。
2. 创世、问答、推演等非编译操作的完整用量账本；本记录只给出可读取的 CompileRun 用量，不冒充全链路成本。
3. 短输入仍产生较多输出 tokens、耗时 32–48 秒的原因和优化；先比较受控样本，再选择模型参数或编译策略。
4. 语义首轮传输异常的重复性与根因；最终发布候选的同一源码/镜像再次跑通。
5. 适用部署环境预算批准、严格 preflight、完整许可审计和发布 CI。

## 可复验命令

```bash
# 在隔离应用/数据库中执行，应用须已配置默认模型和运行 guard
node scripts/acceptance.mjs http://127.0.0.1:4311
# 需要人工抽查时明确保留，抽查后只清理本次 WORLD_ID
node scripts/acceptance.mjs http://127.0.0.1:4311 --keep-world
```

默认完成或异常结束时自动核对并清理本次唯一 fixture；默认模型不可用时不创建世界。HTTP
请求和任务轮询均有期限，不自动重试付费生成/写操作；编译失败或超时先请求取消自身任务。
