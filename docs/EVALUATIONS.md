# 评测与问答记录

检索评测与答案评测在开始时捕获一个正史版本；同轮所有用例、查询改写后的重检索和
回答依据都使用该版本。评测过程中人工合并出新版本，不会改变这轮评测的依据。

答案评测只保存评测结果，不进入普通问答历史，也不会自动沉淀、创建待审 Change 或
触发正史合并。它使用正常的模型用量统计。普通问答仍保存历史；明确要求沉淀，或默认
重复提问条件满足时，模型产物只进入待审队列。关闭沉淀后不会由重复提问条件重新开启。

裁判成绩只接受 0 到 1 之间的有限数值，页面换算为 0 到 100 分。合法的零分会保留。
无效 JSON、缺失或错误类型、越界和非有限分数均为“未评分”；不通过截断修成有效成绩。
均分只计算有效用例，同时显示有效数/总数。没有有效用例时不显示数值均分，也不参与榜单。
部分有效的一轮仍展示均分和样本数，不能把它当作全部用例都成功。

升级需要执行 `pnpm db:deploy`，使 `eval_runs.score` 允许空值。迁移不改写旧成绩或世界
历史。读取旧答案评测时，会根据原有逐例结果重新计算展示值，因此“所有例都未评分，
旧汇总为 0”的记录显示为“未评分”；真实的逐例 0 分仍是有效成绩。旧版已经截断为 0/1、
且没有保留原始裁判输出的结果无法可靠追溯，应重新评测后再比较。

本变更不证明真实模型质量。新版本产生空成绩后，仍把 `EvalRun.score` 声明为必填
`Float` 的旧 Prisma 客户端可能在读取结果时直接失败，不能只检查页面显示。
2026-11-07 隔离验证确认：从旧 app `34c34993a198…`、worker `dc4c39b03d75…`
镜像提取的相同客户端，用与其摘要一致的运行库和引擎读取合法数值成功，读取含空成绩
的记录报 `P2032`；当前客户端保留空值并正常读取。这是客户端兼容证据，不是整套旧镜像
回退通过。

**含空成绩的新库不能直接交给上述旧版使用。** 回退前须确认目标客户端、迁移和完整
数据状态兼容；没有匹配证据时停止切换，保留当前应用与数据库。需要回到更旧数据结构
时，先保留当前完整备份，再将升级前恢复点恢复到独立数据库验证，并明确升级后新增
数据的保留和迁回方案。该路径未验证前不能当作可用回退方案；不可覆盖唯一的新库。
不能直接恢复旧列的非空约束，也不要将未评分填零或删除评测记录来制造兼容。
应用回退与数据恢复的区别见 [累计用量部署说明](./LLM_USAGE_ROLLOUT.md#应用回退与备份恢复分开决策)。
