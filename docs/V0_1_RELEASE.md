## 首版交付什么

2026-09-30 用户确认首发验收目标为**本机单人、不开放外部访问**。公网网关认证、TLS、
公网限流和跨主机 HA 在此发布范围内记为 N/A，而非伪造通过；将来开放受控主机访问时，
仍须按 `DEPLOYMENT_SECURITY.md` 的严格生产契约验收。现有生产 strict 预检不改为宽松模式；
本机首发的独立适用性预检已补入源码、尚未验证，见 [LOCAL_DEPLOYMENT.md](./LOCAL_DEPLOYMENT.md)。
数据正确/恢复、进程并发、模型用量、内容质量、许可、
干净安装及同提交 CI 仍是首版门槛。

2026-10-01 用户进一步确认本机个人使用不设消费额度，只显示累计用量，由本人判断。
因此本机范围不再等待批准的永久费用/token 上限；预算 guard 保持可选，不改生产 strict。
独立于预算配置的持久化 LLM 累计统计、只读 API 和总览卡片已补入源码，包含重试、
未知 usage 与记录起点说明；尚未应用迁移或执行验证，不算运行时完成。既有 CompileRun
用量仅是单任务统计。口径、缺漏边界与待执行步骤见 [LLM_USAGE.md](./LLM_USAGE.md)。

v0.1 是可安装、可持续使用的单人世界观与编年史创作工作室。首发验证本机部署：
用户从种子设定或半成品文稿出发，完成导入、编译、人工审阅、正史合并、继续创作、检索问答
及导出，并能追溯来源、查看版本和恢复失败任务。未来受控主机对外提供访问时，按已有部署契约
配置认证、TLS、限流及备份。

首版保留已经承诺的世界治理、创作台、编年史/图谱、一致性检查、检索问答、评测、技能管理、
导出与 MCP；每个入口都要有实际行为和失败处理。公网多租户、多人实时协作、NPC 运行时、
移动应用和未经验证的高可用集群不属于首版功能范围。
