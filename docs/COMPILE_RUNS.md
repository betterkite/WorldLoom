# 编译任务的版本与恢复

MCP 素材编译、素材页面编译和章节定稿共同调用编译任务创建服务。创建服务在短事务内
取得与合并一致的世界锁，重新读取世界主版本，并按该版本读取纪元、条目和事件目录。
保存的上下文与 `baseVersion` 使用同一个快照。模型调用在事务外执行。

相同来源、章节、原文和版本的排队或运行任务只在保存的上下文仍相同时复用。
世界推进到新版本后，新请求创建新任务；不会把旧任务改标为新版本。编译完成时仍检查
主版本是否已变化，过期结果不进入待审队列。模型产物始终需要人工审阅后才能合并。

旧任务的目录可能没有固定排序，因此执行前按 UID 与字段值核对其记录版本的目录，
不要求相同数组顺序。核对通过的旧任务沿用原上下文和已完成块恢复；核对不通过的任务
在模型调用前失败，保留原文、上下文和基准版本。此时从素材或章节入口重新发起编译，
不要反复恢复旧任务，也不要直接修改它的版本字段。

该核对针对版本化目录，不能恢复旧运行已丢失的模型输出或非版本化世界简介历史。
已经完成的历史任务不被重写。本次改变不需要数据库迁移，也不自动升级运行中的服务。

并发与旧任务兼容检查见 `tests/compile-snapshot.test.ts`，取消、故障恢复、来源和过期
保护见 `tests/compile-run.test.ts`。测试使用合成世界和显式模型替身，不代表创作质量验收。
