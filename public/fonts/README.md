# WorldLoom bundled fonts

This directory holds the unmodified Google Fonts WOFF2 files used by the existing
five font families, their complete OFL-1.1 license texts and a pinned provenance
manifest. See `manifest.json` for per-file sources and SHA-256 digests.

Fonts retain their own licenses; WorldLoom's MIT license does not relicense them.
All original normal-style Unicode subsets are retained. The five Latin files are
preloaded; the remaining subsets load only when their Unicode ranges are needed.

This inventory is engineering evidence, not approval of the complete release.
